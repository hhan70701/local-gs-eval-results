## 对照 README 预期（Codex 分析）

- cam3 / rife_g：fg ΔPSNR=+2.482046 dB，ΔLPIPS=-0.009750；达到前景双指标均值不下降。逐目标双指标均不差为6/6，不应只用均值判断全部视点。
- cam3 / strict_g：fg ΔPSNR=+2.453108 dB，ΔLPIPS=-0.011027；达到前景双指标均值不下降。逐目标双指标均不差为6/6，不应只用均值判断全部视点。
- cam5 / rife_g：fg ΔPSNR=-0.209051 dB，ΔLPIPS=+0.001436；未达到前景双指标均值不下降。逐目标双指标均不差为2/4，不应只用均值判断全部视点。
- cam5 / strict_g：fg ΔPSNR=+0.228667 dB，ΔLPIPS=+0.000090；未达到前景双指标均值不下降。逐目标双指标均不差为3/4，不应只用均值判断全部视点。

本轮固定窗口排除了第六轮“不同变体重新裁剪/编码”这个混杂因素；但第六→七轮还同时改变了逐对选择与触发方式，不能把跨轮总收益全部分配给某一个改动。门限0.03由上游根据同场景前序实验提出；本轮结果是继续验证，不是独立场景上的泛化评估。
